# global-warming
## Моя идея для проекта:
> не использовать технику у которой нагреваеться мотор машина, автобус, и т.д.
> меньше использовать уголь
> повышение энергоэффективности
> восстановление лесов
> экологичное сельское хозяйство
> международное сотрудничество и экономические механизмы.

> выбраная идея:
 не использовать технику у которой нагреваеться мотор машина, автобус, и т.д.

план разроботки:
/you - комада которая рассказывает о том как именно ты можеш помочь

/start - команда которая выдаёт рассказ как помочь природе могут люди а не только ты

/paint - картинка на которю ты нажимаеш и бот выдаёт решение как на этом можно помочь природе
